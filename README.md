AI-Based Resume Screening and Candidate Ranking System
An AI-powered recruitment system that automatically screens resumes and ranks candidates based on job requirements using Machine Learning and Natural Language Processing (NLP).
The project uses:
     TF-IDF Vectorization
     Cosine Similarity
     NLP Text Preprocessing
to compare resumes with job descriptions and generate candidate rankings based on relevance scores.

Features
     Resume PDF Processing
     NLP-based Text Cleaning
     Automatic Candidate Ranking
     Similarity Score Generation
     CSV Output Support
     Technologies Used
     Python
     Scikit-learn
     NLTK
     Pandas
     Machine Learning
     Natural Language Processing
